# Домовой

«Домовой» — заготовка Telegram-бота для сбора обращений жителей по работе управляющей компании. Используются Python, long polling в aiogram, конфиги JSON и SQLite. Английская версия: [README.md](README.md).

## Что уже реализовано

Текущий каркас загружает настройки окружения, создаёт схему SQLite и поддерживает переход из группового чата дома в личный чат с ботом:

1. Житель отправляет `/report` в настроенной группе.
2. Бот присылает кнопку со ссылкой на личный чат и ID исходной группы.
3. Команда `/start report_<chat_id>` находит дом по этому ID и показывает его адрес.

Мастер заполнения заявки, сбор профиля, сохранение обращений и медиа, управление ролями, назначение ответственных, смена статусов и уведомления пока не реализованы. Сейчас `ADMIN_TELEGRAM_ID` только добавляет приветствие администратора; постоянные права он не выдаёт.

## Требования и локальный запуск

- Python 3.11 или новее
- Токен Telegram-бота от BotFather
- Числовой Telegram ID начального администратора

Из корня проекта выполните:

```sh
python -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

Укажите `BOT_TOKEN` и `ADMIN_TELEGRAM_ID` в `.env`. Переменная `DATABASE_PATH` необязательна; по умолчанию используется `./data/domovoy.sqlite3`, относительный путь считается от корня проекта. Замените пример ID группы и адрес в `config/houses.json`, добавьте бота в эту группу и запустите:

```sh
python -m domovoy
```

Бот работает через long polling, поэтому процесс должен быть постоянно запущен. Для работы нужны действительные учётные данные и доступ к Telegram API.

## Конфигурация

Все примеры конфигурации записаны в JSON и редактируются напрямую:

- `config/houses.json` связывает ID группового чата с ID дома и адресом. Указывайте точный числовой ID, включая минус у группового чата.
- `config/classification.json` описывает места, категории для каждого места и обязательные или необязательные поля категорий. Это заготовка будущей конфигурации; работающий бот её пока не читает.
- `config/statuses.json` содержит список статусов и начальный статус. Пока не используется кодом бота.
- `config/responders.json` связывает ID домов с Telegram ID ответственных. Пока не используется кодом бота.

Сейчас JSON загружается без проверки схемы и согласованности ссылок между файлами. Не храните реальные секреты в этих файлах. `.env`, базы SQLite и виртуальные окружения исключены из Git.

## Структура проекта

- `src/domovoy/__main__.py` — запуск и long polling.
- `src/domovoy/config.py` — настройки окружения и загрузка JSON.
- `src/domovoy/handlers.py` — обработчики `/report` и `/start`.
- `src/domovoy/database.py` — начальные таблицы SQLite для пользователей, заявок, полей, медиа и истории статусов. Миграций и функций доступа к данным пока нет.
- `config/` — безопасные примеры JSON-конфигов.
- `AGENTS.md` и `AGENTS.ru.md` — синхронные руководства разработчика на английском и русском с требованиями к поведению проекта.

Тестовый набор, форматтер, линтер, система миграций и контейнер для развёртывания пока не настроены.
