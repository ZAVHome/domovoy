# Домовой

«Домовой» — Telegram-бот для сбора обращений жителей по работе управляющей компании. Используются Python, long polling в aiogram, конфиги JSON и SQLite. Английская версия: [README.md](README.md).

## Возможности

- Житель начинает заявку в настроенной группе дома и продолжает в личном чате по deep link.
- Бот предлагает заполнить необязательные данные профиля, затем проводит жителя по настроенным местам, категориям и текстовым полям. Создание можно отменить; заявка сохраняется после подтверждения.
- Житель может постранично просматривать заявки командой `/my_reports`, открывать детали и историю статусов.
- Назначенные ответственные командой `/reports` получают список заявок своих домов, просматривают их и последовательно меняют статус `new → in_progress → resolved → closed`.
- Администратор из `ADMIN_TELEGRAM_ID` видит заявки всех домов и может установить любой статус.
- Ответственные получают уведомления о новых заявках, жители — об изменении статуса. Ошибка отправки уведомления записывается в лог; изменение в базе сохраняется.

Приём фото и видео, управление конфигурацией внутри бота и восстановление незавершённого диалога после перезапуска пока не реализованы. Состояние мастера хранится в памяти и теряется при остановке процесса.

## Требования и запуск

- Python 3.11 или новее
- Токен Telegram-бота от BotFather
- Числовой Telegram ID начального администратора

Из корня проекта выполните:

```sh
python -m venv .venv
source .venv/bin/activate
pip install -e .
cp .env.example .env
```

Укажите `BOT_TOKEN` и `ADMIN_TELEGRAM_ID` в `.env`. `DATABASE_PATH` необязательна; по умолчанию используется `./data/domovoy.sqlite3`, относительный путь считается от корня проекта. Проверьте JSON-файлы в `config/`, добавьте бота в настроенные группы и запустите:

```sh
python -m domovoy
```

Бот работает через long polling, поэтому процесс должен быть постоянно запущен. Ответственные должны хотя бы один раз открыть личный чат с ботом, чтобы он мог присылать им уведомления. Для работы нужны действительные учётные данные и доступ к Telegram API.

## Конфигурация

- `config/houses.json` связывает ID групповых чатов с ID домов и адресами. Указывайте точный числовой ID, включая минус у группы.
- `config/classification.json` задаёт места, категории и текстовые поля. Поля могут быть обязательными и необязательными; поле с ID `description` сохраняется как описание заявки.
- `config/statuses.json` должен содержать статусы `new`, `in_progress`, `resolved`, `closed` именно в таком порядке; только `new` отмечается начальным.
- `config/responders.json` связывает каждый `house_id` с Telegram ID ответственных. Администратор задаётся отдельно через `ADMIN_TELEGRAM_ID`.

При запуске конфигурация проверяется, включая ссылки на дома между файлами. Изменяйте JSON напрямую, чтобы обновить назначения и категории. Не храните в них секреты. `.env`, базы SQLite и виртуальные окружения исключены из Git.

## Данные и доступ

SQLite хранит профили жителей, заявки, значения дополнительных полей и историю статусов. При запуске применяются миграции схемы с сохранением существующих записей. Создание заявки защищено токеном идемпотентности, смена статуса выполняется условно в транзакции. Житель видит только свои заявки. Ответственный имеет доступ только к назначенным ему домам, администратор — ко всем домам. Защищайте файл базы как данные приложения.

## Структура проекта

- `src/domovoy/__main__.py` — проверка конфигурации, инициализация базы и long polling.
- `src/domovoy/config.py` — настройки окружения и загрузка проверенных JSON.
- `src/domovoy/handlers.py` и `src/domovoy/states.py` — команды Telegram, callbacks и мастер заявок.
- `src/domovoy/repository.py` и `src/domovoy/database.py` — операции SQLite и миграция схемы.
- `config/` — безопасные примеры конфигурации домов, классификации, статусов и ответственных.
- `artifacts/` — планы работ и краткие отчёты на русском и английском в последовательно нумеруемых папках, например `001-text-report-mvp/`.

Стандартные проверки: `python -m unittest discover -s tests` и `python -m compileall src tests`. Форматтер, линтер и контейнер не настроены.
