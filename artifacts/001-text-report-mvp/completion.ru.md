# Выполнение: MVP текстовых заявок

## Сделано

- Добавлена проверка конфигурации домов, классификации, статусов и ответственных при запуске; примеры категорий и статусов приведены к русскому языку.
- Добавлены метаданные миграции SQLite и поле `profile_prompted`, сохранение заявок и динамических полей, история статусов и выборки с проверкой доступа.
- Реализованы мастер жителя, необязательные поля профиля, обязательные и необязательные текстовые поля, отмена и подтверждение, просмотр заявок жителем, обработка ответственными, переходы статусов и уведомления.
- Обновлены README и правила проекта на русском и английском; добавлены тесты стандартной библиотекой.

## Проверки

- `PYTHONPATH=src python -m unittest discover -s tests -v` — успешно прошли 5 тестов: сохранность данных при миграции, профиль, история заявок, ограничения доступа и проверка конфигурации.
- `python -m compileall src tests` — успешно.
- Проверка JSON и `git diff --check` — успешно.

## Ограничения

В локальном окружении не установлен aiogram и нет Telegram credentials, поэтому импорты обработчиков и живой сценарий в Telegram не проверялись. Состояние FSM хранится в памяти и теряется при перезапуске процесса. Приём фото/видео и управление конфигурацией из бота не входили в объём работ.
