# Plan: Set the Bot Version and Commit Rule

## Goal

Set the current package version to `0.01` and document a `0.01` version increase before every commit intended for GitHub.

## Scope

- Update `pyproject.toml` to version `0.01`.
- Add the version increment rule to English and Russian project instructions.
- Keep the commit guidance accurate about the existing initial commit.
- Record this work in a bilingual plan and completion report.

## Stages

1. Inspect current version and commit guidance.
2. Update package metadata and synchronized instructions.
3. Review the diff and record completion.

## Acceptance Criteria

- Package metadata says `0.01`.
- Both instruction files say to increment by `0.01` for each GitHub-bound commit.
- English and Russian guidance agree.
- No commit is created as part of this task.
