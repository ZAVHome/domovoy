# План: коммит и отправка текущих изменений проекта

## Цель

Создать коммит для GitHub с текущими изменениями проекта и отправить его в `origin/master`.

## Объём

- Соблюсти правило проекта, увеличив версию с `0.01` до `0.02`.
- Включить ожидающие коммита двуязычные изменения правила версий и материалы этой работы.
- Проверить staged-файлы и формат diff перед коммитом.
- Отправить коммит в настроенный GitHub remote и проверить результат.

## Этапы

1. Увеличить версию пакета и записать двуязычный план этой работы.
2. Добавить нужные изменения в индекс и проверить staged diff.
3. Создать коммит с повелительным сообщением.
4. Отправить коммит на GitHub и записать результат.

## Критерии приёмки

- Коммит содержит версию `0.02` и все ожидающие изменения проекта.
- В коммит не попали секреты, базы данных и виртуальные окружения.
- `origin/master` указывает на новый коммит либо задокументирована проблема аутентификации/remote.
